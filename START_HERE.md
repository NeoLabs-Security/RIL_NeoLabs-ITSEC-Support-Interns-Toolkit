# Start Here — IT Security Support

## Purpose

This toolkit teaches interns to diagnose, secure, restore and document endpoint, account, network and service issues in authorised environments.

## Before practical work

1. Confirm the assigned asset, ticket, requester and approved access level.
2. Record the reported symptom and current state before changing anything.
3. Begin with read-only inspection and collect only evidence relevant to the ticket.
4. Prepare a rollback plan before modifying configuration.
5. Obtain approval for changes affecting accounts, permissions, firewalls, services, packages, updates or security controls.
6. Validate the result and document what remains unresolved.

## Escalation boundary

Escalate to the SOC track when the evidence suggests compromise, malicious activity, credential misuse or a security incident. Do not delete suspicious files, clear logs or reset systems merely to close a ticket.

## Repository boundary

This public repository must not contain:

- live credentials or private keys;
- real user or device information;
- private infrastructure addresses;
- raw evidence from cohort systems;
- mentor answer keys;
- active assignment details;
- scripts that make uncontrolled changes.

## Learning order

Follow `LEARNING_PATH.md`. Diagnosis, documentation and change control come before hardening automation.
